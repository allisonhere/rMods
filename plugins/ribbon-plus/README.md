# ribbon-plus

A fork of [ribbon](https://github.com/robonuggets/ribbon) by Jay E (MIT, see `LICENSE`).

A quiet usage band above the prompt. It shows how much of your 5-hour and 7-day usage is left, and whether the prompt cache is warm or cold.

- One short row of bars by default. `▲` opens the full band, `▼ Tiny` (or `/ribbon-plus`) goes back. The choice is remembered across sessions.
- Bars run from green to red as a window drains.
- The row and the cache card follow the pane width.

Turn the original ribbon off before installing this, so two bands don't show.
